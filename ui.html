口径 · 2026-10-19

时间窗
裁判日期 2024-01-01 至 2026-10-31
案件类型
专利 / 商标 / 著作权 / 不正当竞争 / 其他知产
执行类
案由含「执行」且不含「之诉」的，不计件、不计判赔
成件
按案号：同案的「之一」「之二」算一件，不同案号各算一件
二审
正文点到原审案号、且当事人有交集才并入，否则单独一件
判赔
主文赔偿项之和，剔诉讼费；「在 X 元范围内」不另计；裁定书的案件金额不用
等级
A>100 / B 51–100 / C 21–50 / D 6–20，基数 = 自身 + 关联
法宝
逐笔全量核查；查不到不改变金额，只标注来源

只统计已公开裁判文书。「近两年无知产案件」的意思是没查到公开文书，不是没打过官司。

使用提示

本包已内置 Python 与 Node，不用另行安装。凭证只存在这台电脑上。外发或拷给同事前，请删除「凭证.txt」「法宝凭证.txt」和「缓存」里的数据。
