# 涉诉画像工作台

给一份企业名单，产出知产涉诉画像主表与关联主体附表。口径版本：**2026-10-19**（时间窗 2024-01-01 至 2026-10-31，按案号成件，执行类不计件不计判赔）。

## 同事怎么用

请下载 Release 里的 **[kehu-shesu-huaxiang-green-20261019.zip](https://github.com/WU326320/kehu-shesu-huaxiang/releases/download/v2026-10-19/kehu-shesu-huaxiang-green-20261019.zip)**。

解压后双击 `启动工作台.bat`，浏览器会打开 http://127.0.0.1:8777 。**不用自己安装 Python 或 Node。**

第一次使用，在页面上完成三件事：

1. **天眼查**（必填）：点「开始授权」，用浏览器打开链接并输入 6 位验证码，再点「我已授权，继续」。
2. **企查查**：把 token 粘进输入框并保存（形如 `Bearer ……`）。
3. **法宝**（可选）：粘贴 Authorization。不填也能出表，只是跳过判赔核查。

然后上传 Excel / CSV 名单，点「开始」。详细说明见包内 `说明.md`。

## 本仓库是什么

仓库里只有源码（`app.py`、`ui.html`、`core`、`pipeline`、配置模板和说明），**不含**便携运行时、缓存、输出和任何凭证。要使用请下上面的绿色包。

凭证只保存在使用者本机的 `凭证.txt` / `法宝凭证.txt`，不要提交、不要随包外发。外发前请删除这两个文件和 `缓存` 里的数据。

## 开发说明

绿色包的 Python 是 Windows embeddable 发行版（无 tkinter），界面因此做成本地网页，而不是桌面窗口。在已解压的绿色包里可以用：

```text
runtime\python\python.exe 自检.py
```

核对环境和口径规则。
